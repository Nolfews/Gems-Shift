# 💎 Gems Shift

**Gems Shift** is a 2D/3D platformer focused on exploration, puzzles, and elemental transformation.

## 🎮 Concept

The player can transform their body into different elements by collecting and using powerful **Elemental Gems**.

Each element provides unique abilities that can be used to:

* 🔥 A dash and the ability to shoot fireballs
* 💧 Healing ability and the ability to grow plants
* 🌪️ Jump higher and push back enemies
* ⚡ Teleport and electrocute enemies
* 🌿 Create platform and climb the walls
* 🧩 Solve environmental puzzles

## 🛠️ Project Status

> 🚧 **In development**

Features, mechanics, levels, and elements are subject to change during development.
